## Making and assembly
先试印滑动与螺纹配合试片；建议0.2 mm层高。原版装配经验：底座底面向下打印稳定，侧孔可能需局部支撑、清孔；本版保留真实横向内螺纹，需试印验证，不宣称直接可打印旋合。打印螺纹轴尽可能竖直时底座需重定向及支撑，最终由打印准备阶段决定。原圆柱竖直打印、顶部方榫倒角导入的做法保留为记录，但扩大斜承托台带来新的悬垂，需重新评估方向及支撑，避免损伤配合面。碗按碗口水平重新定向，加厚碗底下方与凹槽可能需支撑，不要在食物腔留下支撑疤。
本版无螺母；插入圆柱后将碗沿竖直方向套在斜台与方榫上，从背面旋入名义M5x12手拧螺丝，对准五个浅凹点之一，轻轻顶紧勿暴力拧紧。调节时托住碗再松螺丝约2.5圈（轴向2 mm，已超过浅凹1.2 mm），确认端部退出后才升降；保持至少22 mm导向插入。五个凹点不是永久防拔出止挡，松开后仍可拔出或转动，需对准背面点位和碗口方向后锁定。清洗时向上拔出碗，与底座分开；原型未验证食品接触，不直接盛食。PETG样机1 kg静载、稳定性、凹点磨损与螺纹寿命待实测。旧版150 mm最高点对应旧浅碗，现在最高碗口约163.8 mm，用户已接受。
