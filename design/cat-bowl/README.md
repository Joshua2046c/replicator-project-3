# 圆柱升降斜口猫碗

## 目标
用户标注要求：升降主体为光滑圆柱，只有顶部采用凸起方榫连接碗底；碗底允许加厚；无定位卡点，取消刻槽；锁紧螺丝在背面直接旋入下部底座内螺纹，不要螺母及额外方块。保留110–150 mm碗口最高点高度、40 mm行程和130 mm展示高度。碗直径140、底径90、外深18、壁厚3 mm、倾角10°。默认圆柱直径28、圆孔28.6、底座160×8、套筒40外径/66高；最高位置插入22 mm。顶部16 mm方榫与16.5 mm盲孔、11 mm插入不变。碗底使用圆形渐扩加厚，不是外露方块。

## 连接与标准件
round_slide：free圆柱滑动配合，无卡点无刻线；bowl_detach：free方榫肩面承重；height_lock：free_after_kit_rejection。printed-screw-joint-v1在曲面孔入口位置连续产生无效BRep；真正曲面贯通切削需要外侧与内侧的螺纹越程，kit对此悬空孔口明确返回ScrewJointNotApplicableV1，故用bd_warehouse的ISO螺纹库以外螺纹负形完成内部M5x0.8孔，直径补偿0.45 mm，非圆孔替代。后半套筒为接收体，无螺母、无外凸方块。螺丝为目录ISO4762 M5x12；原始精细STEP为17个相接实体，现用同一标准库的头部/内六角和连续ISO螺旋生成单实体，轴长已裁切到12 mm。背面默认定义为碗口较高的-X侧，螺丝轴向+X插入，中心高54 mm。

## 当前检查与未完成项
圆柱及加厚碗体完成，110/150 mm极限位置已经检查；它们与底座无体积干涉。螺丝尝试置于旋入位置时，精细螺纹、单实体以及隐藏段简化方法均遭遇180秒装配计算超时，不能重复声明旋合已验证。最终模型保留全长外螺纹，将螺丝后移展示在(-44,0,54)，轴线对准背面孔；这是分解展示，不是已锁紧状态。设计的拧紧参考坐标为(-26,0,54)，尚未成功提交/验证。未修改用户的直接螺纹要求来迁就导出。未完成：螺丝最终装配位置、螺纹相位配合及实物锁紧验证。其余造型可查看、可继续编辑；本版不属于可直接生产的完整装配验证结果。

## Making and assembly
先试印滑动与螺纹配合试片；建议0.2 mm层高。原版装配经验：底座底面向下打印稳定，侧孔可能需局部支撑、清孔；本版改为真实横向内螺纹，需试印验证，不宣称直接可打印旋合。打印螺纹轴尽可能竖直时底座需重定向及支撑，最终由打印准备阶段决定。圆柱竖直打印，顶部方榫倒角导入。碗按碗口水平重新定向，加厚碗底下方需支撑，不要在食物腔留下支撑疤。取消旧版顶部装螺母及刻线的操作：本版无螺母，装配意图为插入圆柱后套碗，从背面旋入M5x12螺丝，轻轻顶紧勿暴力拧紧；最终旋合尚待验证。调节时托住碗再松螺丝，控制碗口最高点不超过150 mm并保持至少22 mm导向插入；无卡点、刻线或永久防拔出止挡。松开后圆柱可转，需调整碗口方向再锁定。清洗时向上拔出碗，与底座分开；原型未验证食品接触，不直接盛食。PETG样机1 kg静载、稳定性与螺纹寿命待实测。
