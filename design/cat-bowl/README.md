# 方柱升降斜口猫碗

## 目标
依两张用户图片制作可拆倾斜碗、方形升降柱、圆形底座及侧面螺丝锁紧装配。110–150 mm高度为用户图示；默认按桌面到碗口最高点解释，40 mm行程，展示130 mm。碗140 mm外径、90 mm底径、18 mm外深、3 mm壁厚、倾角10°。底座160×8 mm，套筒高66 mm、外径40 mm，22 mm方柱滑入22.6 mm方孔；最高档22 mm导向重叠。16 mm方榫插入碗底16.5 mm方盲孔，肩面承重，可垂直拔出。

## 连接与标准件
square_slide：自由方形滑动配合；bowl_detach：自由方榫肩面承重；height_lock：ISO4762 M5x16螺丝与ISO4032 M5捕获螺母，依据当前目录确认的模型。捕获螺母路径先调用printed-screw-joint-v1，若明确拒绝则以free拓扑构建螺母口袋。槽从上方装螺母，螺丝从侧面穿过，螺母靠内侧肩承受顶紧反力。螺丝尖端接触方柱而非虚设锁紧。

## 检查
检查最高与最低位置的实际碗口最高点和实体干涉。默认PETG样机。所有尺寸与倾角可编辑。实体检查不构成载荷、抗倾覆或食品接触认证。最高档需1 kg静载及侧向稳定性实测。

## Making and assembly
先试印滑动配合试片；建议0.2 mm层高。底座底面向下打印，侧孔可能需要局部支撑并清孔；方柱竖直打印，顶部方榫倒角导入；碗按碗口水平重新定向，碗底方插座下方需要支撑，不要在食物腔内留下支撑疤。自上方槽装入M5螺母，再从侧面穿入M5x16螺丝；插入方柱至最低端，套入碗。用内六角扳手轻轻顶紧，勿暴力拧紧。升降时托住碗再松螺丝，升降不越过最高刻线；此版本不设永久防拔出止挡。清洗时向上拔出碗，与底座分开处理。原型未验证食品接触，不直接盛放食物；需食品接触工艺后再投入使用。
