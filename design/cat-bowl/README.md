## Making and assembly
先试印滑动与螺纹配合试片；建议0.2 mm层高。原版装配经验：底座底面向下打印稳定，侧孔可能需局部支撑、清孔；本版是真实横向内螺纹，需试印验证，不宣称直接可打印旋合。打印螺纹轴尽可能竖直时底座需重定向及支撑，最终由打印准备阶段决定。原圆柱竖直打印、顶部方榫倒角导入的做法保留为记录，但本次扩大斜承托台带来新的悬垂，需重新评估方向及支撑，避免损伤配合面。碗按碗口水平重新定向，加厚碗底下方与凹槽可能需支撑，不要在食物腔留下支撑疤。取消旧版顶部装螺母及刻线的操作：本版无螺母，装配意图为插入圆柱后将碗沿竖直方向套在斜台与方榫上，从背面旋入M5x12螺丝，轻轻顶紧勿暴力拧紧；最终旋合尚待验证。调节时托住碗再松螺丝，控制碗口最高点不超过150 mm并保持至少22 mm导向插入；无卡点、刻线或永久防拔出止挡。松开后圆柱可转，需调整碗口方向再锁定。清洗时向上拔出碗，与底座分开；原型未验证食品接触，不直接盛食。PETG样机1 kg静载、稳定性与螺纹寿命待实测。
