# 方柱升降斜口猫碗

## 用户要求
参考两张上传图：碗倾斜，碗与底座分离，以方形桩连接；底座可升降并用螺丝固定。图示最低110 mm、最高150 mm。

## 本版默认值（均可调整）
高度按桌面到碗口最高点解释，行程40 mm。碗口外径140 mm、底径90 mm、外深18 mm、倾角10°、壁厚3 mm。圆底座直径160 mm、厚8 mm，套筒高66 mm、外径40 mm。方柱22 mm，滑孔22.6 mm；可拆连接为16 mm方榫与16.5 mm盲孔、插入11 mm。M5x16内六角螺丝配M5金属捕获螺母，重复调节不依赖打印塑料螺纹。默认PETG装配样机，展示高度130 mm。

## 验收与边界
导出可编辑STEP装配，核对110/150 mm两端位置、40 mm升降行程、方柱防转、可拆碗及锁紧接口。样机应实测最高档1 kg静载和侧向稳定性；CAD不证明承载、锁紧摩擦力或防倾倒。升降范围用柱面刻线提示，松开螺丝时必须手托碗；不设不可拆的防拔出止挡。

## 食品接触
本版为外形与装配样机，不宣称可直接盛食。量产碗体需另行采用经过食品接触验证的材料与工艺。Prusa关于FDM食品接触的说明指出层间缝隙与清洁问题：https://help.prusa3d.com/article/food-safe-fdm-printing_112313 。

## 五金依据
采用已验证bd-warehouse 0.2.0目录的ISO 4762 M5-0.8、长度16 mm螺丝及ISO 4032 M5螺母。采购材质默认不锈钢；品牌、价格、库存不影响本次几何样机。
