# 圆柱升降斜口猫碗

## 用户要求
碗倾斜并与底座分离；升降主体是圆柱，仅顶部采用凸起方榫与碗底连接。碗底允许加厚。升降无需定位卡点；螺丝从背面直接旋入下部底座的内螺纹，无额外方块和螺母。高度保留110–150 mm。标注依据：product/references/uploads/20260922T115012765Z-1-mark.png。

## 默认尺寸与方向
高度按桌面至碗口最高点，行程40 mm。碗外径140、底径90、外深18、壁厚3 mm、倾角10°；圆底座160×8 mm，套筒高66、外径40 mm。圆柱直径28、圆孔28.6 mm，顶部16 mm方榫插入16.5 mm盲孔11 mm。圆形渐扩加厚碗底取代方插座外形。背面定义为碗口高侧-X。M5x12全螺纹螺丝配底座直接M5x0.8内螺纹，样机默认PETG。展示高度130 mm。

## 验收与边界
导出参数化STEP装配；核对110/150 mm两端、40 mm行程、碗底方榫和背面螺纹。圆柱无刻线、卡点或防拔出止挡；最高位置需保留22 mm插入量。圆柱松开时可旋转，锁紧时同时固定高度和方向。调节必须手托碗。打印螺纹配合与寿命、1 kg静载及侧向稳定性需实测。食品接触未验证，此版为装配样机，不直接盛食。
