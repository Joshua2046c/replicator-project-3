# 五档圆柱升降斜口猫碗

## 用户要求
可拆斜碗，升降主体为圆柱，只有顶部用方榫连接。底座背面螺丝直接旋入内螺纹，无额外螺母或方块。当前要求为圆柱背面5个浅凹定位点，两端对应最低和最高；螺栓头适合手拧。用户已接受深碗的最高碗口总高约123.8–163.8 mm。

## 默认尺寸与档位
保持碗口140、外深32、壁厚3、底厚6.5 mm，中央名义内深25.5 mm，倾角10°及R12碗壁根部圆角。底座160×8 mm，套筒直径40、顶高66 mm、根部R19。圆柱28、圆孔28.6，斜台60、匹配凹槽60.6 mm；16 mm方榫与16.5 mm方盲孔不变。
5个凹点沿背面-X等距布置，默认间距10 mm、直径5.8 mm、最大深1.2 mm，入口0.35 mm倒角。柱局部Z为10/20/30/40/50 mm。最低档对应最上方凹点，第五档最高对应最下方凹点；碗口最高点依次约123.8、133.8、143.8、153.8、163.8 mm。最高导向插入22 mm，无永久防拔出止挡。
手拧头为定制六瓣，外径28、厚8 mm，握持棱圆角0.8、端面边倒角0.4 mm；名义M5x0.8螺纹杆头下长12 mm。凹点底面X=-12.8，螺丝头下X=-24.8，轴高Z54。档位中间位置为交付展示位置。

## 交付与验证边界
交付参数化源模型与STEP装配，不采购、不切片、不打印。底座与碗的源代码、形状和最终装配位置保持原样。最低、中间、最高位置均检查了名义螺杆端面与凹点接触、零件无体积干涉；五档中心位置均按54 mm轴高核对。
为避开旧版完整螺纹旋合计算反复超时，STEP螺杆采用库定义的ISO小径简化表示，保留5 mm平端包络用于凹点检查，不含外螺纹螺旋牙形。底座原有真实内螺纹未改。图中的光滑细杆不是实际加工要求：实物必须有M5x0.8外螺纹；本版不能作为一体打印即可锁紧或完整外螺纹加工文件。六瓣头为定制造型，非已验证的购买件。真实旋合、锁紧力和耐磨寿命尚未验证。

## 使用与试验
调节前手托碗，松开旋钮约2.5圈，使螺杆退让2 mm，完全退出浅凹点后再升降；对准所选点位轻拧，不用力过拧。圆柱松开时可旋转，需对准背面点位。样机默认PETG，应先试印滑动、螺纹及凹点配合试片，检验最高档1 kg静载、稳定性和反复调节寿命。食品接触材料与工艺未验证，不直接盛食。
