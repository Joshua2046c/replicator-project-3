## 使用与试验
调节前手托碗，松开旋钮约2圈（M6×1轴向退让2 mm），确认定位端退出1.2 mm凹点后再升降；轻拧勿暴力拧紧。松开时柱仍可旋转，需对准背面点位。默认PETG样机，应先试印滑动和螺纹试片，验证最高档1 kg静载、稳定性及反复调节。食品接触材料与工艺未验证，不直接盛食。
