# 方孔插销定位升降猫碗

## 当前要求
升降柱的五个定位孔、底座对应的背面侧孔及插销杆改为匹配正方形，取消螺纹锁定。本次按背面定位机构理解，圆底盘与圆柱外形保留。当前mark.png未落入工作区，未从旧图冒充读取标注；执行依据为本轮文字及指定Build89模型。

## 实现尺寸（默认值）
五个6.4×6.4 mm方盲孔，深8.5 mm，中心间距10 mm；底座侧孔6.4×6.4 mm。方销6×6 mm、手柄下长14 mm、端部倒角0.5 mm，每侧名义间隙0.2 mm，孔底余隙0.5 mm。五瓣手柄保留28×8 mm。孔间净距3.6 mm，插销中心线插入圆柱8 mm，计入圆弧侧壁及倒角的完整方截面插入约7.18 mm。
圆柱直径28、导向孔28.6、40 mm行程和五档中心不变。手柄推至底座圆筒后止挡，向后直拔；不旋拧。方孔是盲孔，不贯穿圆柱前侧。

## 保留的碗与高度
Build89碗的几何、参数及放置完全不变：147 mm口径、35.6 mm外深、六个宽圆弧瓣、4.2 mm瓣差、10度倾角。最高口沿名义范围127.9404–167.9404 mm，对应用户已确认约128–168 mm。该范围为孔中心对齐的几何值，受力会有配合间隙造成的微量下沉。

## 检查与使用边界
Build93四个有效实体；6对零件无体积穿插。插销与柱最小间隙0.2 mm，手柄与底座接触；碗/承托面接触、碗/插销间隙20.6591 mm。近景检查了五个方孔、底座开口和光滑方销，未残留内外螺纹。
