# 圆柱升降斜口猫碗

## 用户要求
碗倾斜并与底座分离；升降主体是圆柱，仅顶部采用凸起方榫与碗底连接。碗底允许加厚。升降无需定位卡点；螺丝从背面直接旋入下部底座的内螺纹，无额外方块和螺母。用户已确认加深碗后总高更新为约123.8–163.8 mm。标注依据：product/references/uploads/20260922T115012765Z-1-mark.png。

## 默认尺寸与方向
高度按桌面至碗口最高点，行程40 mm。碗外径140、底径90、外深32、壁厚3 mm、倾角10°；圆底座160×8 mm，套筒高66、外径40 mm。圆柱直径28、圆孔28.6 mm，顶部16 mm方榫插入16.5 mm盲孔；斜承托面中心以上方榫露出7 mm。圆形渐扩加厚碗底带60.6 mm匹配凹槽；承托面与碗底均为10°倾角，凹槽中心深2 mm。底座用R19 mm相切圆弧过渡。背面定义为碗口高侧-X。M5x12全螺纹螺丝配底座直接M5x0.8内螺纹，样机默认PETG。当前原位展示的碗口最高点143.787 mm。

## 验收与边界
导出参数化STEP装配；核对约123.8/163.8 mm两端、40 mm行程、碗底方榫和背面螺纹。圆柱无刻线、卡点或防拔出止挡；最高位置需保留22 mm插入量。圆柱松开时可旋转，锁紧时同时固定高度和方向。调节必须手托碗。打印螺纹配合与寿命、1 kg静载及侧向稳定性需实测。食品接触未验证，此版为装配样机，不直接盛食。

按product/references/uploads/20260922T125215893Z-1-image.png黄色侧视图，只改变碗体深度与碗壁根部圆角：外深32 mm、圆角R12为默认初值；底厚6.5 mm不变，中央内深25.5 mm。其余所有参数和装配位置不变。用户已确认保留深碗和其他零件，将总高要求更新为约123.8–163.8 mm；升降行程仍为40 mm。螺丝未装配的既有问题仍阻碍整机验收。
